# Algebrasteg

Träna algebra ett steg i taget, med nya uppgifter varje gång:

- **Förenkla uttryck** (nivå 1–5): markera x-termerna, samla x-termer och tal, multiplicera in parenteser.
- **Lös ekvationer med balansmetoden** (nivå 1–5): välj vad du gör på båda sidor, skriv den nya ekvationen och kontrollera svaret. En våg visar vad som händer när alla tal är positiva.

Filer: `index.html`, `algebra.js` (övningarna), `app.css`, `stil.css`, `manifest.webmanifest` + `sw.js` (installerbar app som fungerar utan internet).
Publiceras med GitHub Pages från grenen `main`.
